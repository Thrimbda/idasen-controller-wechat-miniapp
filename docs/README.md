# Idasen 微信小程序

本目录包含通过微信小程序控制宜家 Idasen 升降桌的实现。

## 目录结构

- `app.*`：全局配置与样式。
- `pages/`：核心页面（蓝牙连接、桌子控制、设置）。
- `utils/`：蓝牙封装、协议转换、存储等基础工具。
- `types/`：类型扩展。
- `docs/`：文档说明。

## 快速开始

1. 安装依赖（首次准备时执行）：
   ```bash
   cd wechat-miniapp
   npm install
   ```
2. 运行类型检查：
   ```bash
   npm run dev:types
   ```
3. 运行单测（主要覆盖协议解析与工具函数）：
   ```bash
   npm test
   ```
4. 使用微信开发者工具导入 `wechat-miniapp/` 目录，并在真机下测试 BLE 功能。

## 核心功能概览

- **蓝牙连接页**：扫描并连接名称包含 `Desk` 的设备，显示附近设备列表与历史连接记录。
- **桌子控制页**：实时展示高度与速度，长按按钮手动上/下，快速切换坐姿与站姿预设并支持一键停止。
- **设置页**：配置坐/站预设高度、切换显示单位（厘米/英寸）、开启/关闭自动重连开关。
- **蓝牙服务**：`utils/desk-service.ts` 负责封装扫描、连接、指令与目标高度闭环控制；`utils/desk-protocol.ts` 负责 LINAK GATT 协议解析与指令编码。

## 注意事项

- 需在真机环境授权蓝牙以及（Android）定位权限，确保桌子未被其它设备占用。
- 目标高度移动采用通知闭环，若超时或速度异常会自动发送停止指令。
- 自动重连开关与预设、单位均保存至小程序本地存储，可通过设置页重置。

更多设计细节请参考仓库根目录的 `design.md`。
